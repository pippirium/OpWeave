# OpWeave

[English](README.md)

OpWeave は、Unity Editor の操作を型付きの操作として検索・接続・実行するワークフローツールの構想です。人と AI エージェントが、入力、実行順序、完了条件を検証しながら、繰り返し使える編集作業を組み立てられることを目指します。

## 開発状況

**OpWeave は設計・初期開発段階です。** リリース済みのパッケージや利用可能なインストール手順はまだありません。以下は目標であり、実装済みの機能ではありません。

## 予定している機能

- 型、互換性、副作用による操作カタログの検索。
- 制御フローとデータフローを分けた、ビジュアルなノードエディタでのワークフロー作成。
- ワークフローの検証と、各操作の完了条件を待ちながら行う逐次実行。
- 実行状態とエラーの追跡、および操作ごとの Undo・再実行に関する情報の提示。
- AI エージェントが操作を発見し、ワークフローを検証するためのインターフェース。

初期スコープは Unity Editor の編集操作です。ゲーム実行中のビジュアルスクリプティング、他のアプリケーション、任意の C# コードの無制限実行は初期対象外です。
