# OpWeave

[English](README.md)

OpWeave は、Unity Editor の操作を型付きのOperationとして検索・接続・実行するワークフローツールです。Windows v1の開発と受入検証は完了し、公開用パッケージの配布準備を進めています。

## 開発状況

**Windows v1 の開発・受入検証は完了していますが、この公開リポジトリにはまだ配布用Unityパッケージがありません。** バージョンは **`0.1.0`** に確定しており、[VERSION](VERSION) と [release-lock.json](release-lock.json) に対応関係を記録しています。公開タグとインストール手順は未提供です。

## Windows v1の機能（開発版で検証済み）

- 型、互換性、副作用による操作カタログの検索。
- 制御フローとデータフローを分けた、ビジュアルなノードエディタでのワークフロー作成。
- ワークフローの検証と、各操作の完了条件を待ちながら行う逐次実行。
- 実行状態とエラーの追跡、および操作ごとの Undo・再実行に関する情報の提示。
- AI エージェントが操作を発見し、ワークフローを検証するためのインターフェース。

初期スコープは Unity Editor の編集操作です。ゲーム実行中のビジュアルスクリプティング、他のアプリケーション、任意の C# コードの無制限実行は初期対象外です。
